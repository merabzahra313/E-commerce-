# 🛒 E-Commerce Store Management System (C++)

A comprehensive console-based E-Commerce Store Management System written in **C++**. This project demonstrates the application of Object-Oriented Programming (OOP) principles and File Handling to simulate a real-world online shopping environment.

---

## ✨ Features

### 👤 User / Customer Module
- **Product Catalog:** Browse available products with prices and stock quantities.
- **Shopping Cart:** Add items to cart, view cart summary, and remove items.
- **Checkout & Billing:** Automatic bill calculation with receipt generation.

## 🛠️ Tech Stack & Concepts Used

- **Language:** C++
- **Core Concepts:**
  - **Object-Oriented Programming (OOP):** Classes, Objects, Encapsulation, Inheritance, and Polymorphism.
  - **File Handling (`fstream`):** Storing product inventory and user records permanently.
  - **Data Structures:** Arrays / Vectors for temporary cart management.
